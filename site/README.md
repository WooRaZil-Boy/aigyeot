# 아이곁 개발·검증 자료(정적 페이지)

심사용으로 한곳에 모은 정적 웹 페이지입니다. `index.html`을 브라우저에서 열면 되고(더블클릭), 서버나 빌드가 필요 없습니다. 이 폴더를 통째로 정적 호스팅에 올리면 같은 페이지가 됩니다.

| 메뉴 | 내용 |
| --- | --- |
| 개요 | 핵심 숫자, 실제 주행 기록 다시 보기(release 빌드(제출 APK 이전 판)의 화면·로그·실내 3D, 두 기록을 한 시간 자에서 비교하는 슬라이더), 저장소·APK·실행 방법 링크 |
| 검증 결과 | 울음 감지, 그침 판정, 울음 입력 → 경보·첫 달래기, 자원 사용량, 차량·Pleos 기능 실측(실내 평면 3D에 번호를 단 설명, 표로도 보기), 소리 고르기 시뮬레이션, 음성 질문 LLM 답변 지연, 확인하지 못한 것. 그림은 Observable Plot(`vendor/`)으로 그리고, 마우스를 대면 값과 출처가 나옴 |
| 실제 화면 | 측정하며 남긴 에뮬레이터·휴대폰 화면(release 빌드(제출 APK 이전 판)의 실제 마이크 경로 포함, 누르면 크게) |
| 디자인 시안 | 차·안드로이드·iOS 세 앱의 시안(`design/`, 눌러 볼 수 있음) |
| 개발 도구 | 측정·평가에 쓴 도구, 시험, 직접 돌려 보는 순서 |

- 숫자의 원본은 [tools/measure/README.md](../tools/measure/README.md)와 각 기록 파일입니다. 페이지의 숫자는 그 값을 옮긴 것이고, 항목마다 원본 링크가 있습니다.
- `img/`의 화면은 측정 기록에 남긴 캡처를 줄인 것이고, 3D 포스터와 평면도 그림(`img/cabin-*`·`img/plan-*`)은 디자인 시안의 3D 모형으로 그린 것입니다.
- `design/`은 디자인 시안이며 따로 [README](design/README.md)가 있습니다.
