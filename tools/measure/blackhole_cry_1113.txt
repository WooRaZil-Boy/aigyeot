# 실제 마이크 경로로 연습용 울음 녹음을 넣었을 때 경보가 나는지(리허설 R1) — 2026-11-13 14:28~15:07
요약: 1차(맥 기본 출력도 BlackHole 2ch)는 마이크 소리가 끊겨 경보 없음(실패). 2차(기본 출력을 스피커로 되돌린 뒤)는 파일 A·B 모두 경보(통과, 맨 아래 '2차' 절).
환경: 차 AVD PleosConnect(emulator-5560, `emulator -avd PleosConnect -port 5560 -no-snapshot-save -timezone Asia/Seoul -allow-host-audio`, 운전자 user 10).
      빌드: 서명한 release APK apk/곁빛_아이곁_release.apk(92,000,223 B, sha256 1032864fe7cd325e…, versionName 0.1). 앱을 지운 뒤 설치.
      대조로 같은 날 만든 debug 빌드(app/build/outputs/apk/debug/app-debug.apk)를 한 번 깔았다(아래 4장).
      소리: 울음 파일을 ffmpeg로 맥의 가상 오디오 장치 BlackHole 2ch에만 내보냈다(`-f audiotoolbox -audio_device_index 2`, 장치 번호는 `-list_devices true`로 확인).
      에뮬레이터 마이크가 맥 기본 입력을 받는다. 맥 오디오 설정은 바꾸지 않고 읽기만 했다(`system_profiler SPAudioDataType`).
      14:28 기본 입력·출력은 USBC Headset, 14:32부터 기본 입력·출력·시스템 출력이 모두 BlackHole 2ch(48,000 Hz)였다.
      녹음: Wikimedia Commons 퍼블릭 도메인 울음 녹음(Babys_disappointed_crying), 연습용으로 이어 붙인 파일 A·B.
      A = 88.3초(울음 48.3초 + 조용함 40초), B = 193.3초(같은 울음을 네 번 이음). 둘 다 48 kHz 스테레오 16비트. 첫 소리는 파일 0.89초(그 전은 -40 dBFS 아래).
      대조 녹음: 11-11 같은 경로에서 경보가 났던 75초 연속 울음 녹음(16 kHz 모노, e2e_cry_drive_1111.txt 3장의 cont 녹음).
      맥 부하(1분/5분/15분): 14:28 4.67/18.26/28.05, 14:49 7.98/26.35/38.48, 14:53 7.21/17.07/31.66. 기다리지 않고 쟀다.
시각: 맥 시각과 에뮬레이터 시각(logcat)을 따로 적었다. `adb shell 'echo $EPOCHREALTIME'`를 맥 시각 사이에 다섯 번 재어
      에뮬레이터가 맥보다 약 0.24초 늦었다(왕복 0.12~0.15초라 ±0.08초).
규칙: 앱 코드·문서는 고치지 않았다. 확인하지 못한 것은 미판정. 캡처는 tools/measure/screens_r1_1113/(저장소에 넣지 않음).

## 5. 에뮬레이터가 받는 마이크 소리 확인(실측 프로브 tools/pleos-probe MeasureProbe rec, 16 kHz 모노, 1초마다 rms)
- 소리 없을 때: rms 1.9(6초 내내).
- 파일 A를 틀 때: 1초 rms 128, 317, 258, 736, 167, 1374, 1219, 1871, 3762, 585. 파일 A 앞 10초의 1초 rms(16 kHz 모노로 바꿔 계산)는 157~5,680이라 크기는 비슷하게 닿는다.
- 파형: 대조 녹음을 틀며 받은 12초를 원본과 맞춰 보니 파형 상관 0.125(맞는 시각에서도), 10 ms 크기 곡선 상관 0.33~0.35였다.
  재생 속도를 0.70~1.40배로 바꿔 맞춰도 최고 0.36(0.995배)이었다(속도·음높이 어긋남이 아니다). 0.25초 조각마다 원본에서 맞는 곳을 찾으면 위치가 뒤죽박죽이다.
- 삐 소리: 1 kHz 0.2초(크기 0.3)를 한 번 냈더니 받은 소리는 10~20 ms짜리 조각 넷(1.93·2.07·2.19·2.31초, 약 0.12초 간격)이었고 조각의 10 ms rms는 682~1,734(낸 소리는 약 6,950)였다.
  → 에뮬레이터 마이크 입력이 잘게 끊겨 들어온다. 울음 판별기가 끊긴 조각만 받아 울음으로 보지 못한 것으로 보인다(추측: 판별 점수는 로그가 없어 보지 못함).
- 끊기는 까닭은 미판정. 11-11(경보 남)과 다른 점: ① 맥 기본 출력도 BlackHole 2ch(11-11은 출력을 바꾸지 않음) — 에뮬레이터 소리 출력과 입력이 같은 가상 장치에 걸린다.
  ② 맥 부하가 높았다(15분 평균 28~38, 11-11 시작 때 1분 4.9). 1분 부하가 7.5로 내려간 14:49에 다시 재도 끊김은 같았다.
- 프로브는 확인 뒤 지웠다. 음성 비서 상시 듣기를 멈추면 달라지는지 보려 했으나 강제 종료하자 1초 만에 다시 열려 확인하지 못했다(미판정).
