- 첫 설정: 동의 체크 → 별명 → 저장 → 홈('출발 전이에요', '듣기 꺼짐', '마지막 수유: 기록 없음'). 연결된 폰이 없어 홈에 연결 줄은 없다(8.6 NONE)

- 화면 켜짐·전원 정책 켜짐마다 호스트가 link.wake()를 불렀다(같은 ms에 호스트 스레드에서). 두 번 불려도 link 쪽 신호는 합쳐진다(CONFLATED)
- 시계 점프 경로의 wake는 이 흉내에서 재지 못함(흉내가 CPU를 실제로 재우는지 모름, host_suspend_1104.txt와 같음). JVM 시험 c67_clockJump_wakesLink만

## 3. 연결 화면 상태 표시
- '휴대폰 연결'을 열면 "휴대폰 연결: 다시 붙는 중"(BACKOFF). 로컬 중계를 띄우지 않아 붙지 못한 상태. '연결됨'·"연결됐어요"는 중계가 있어야 해 JVM 시험(LinkTextTest)만

## 4. 끝 상태

- 차는 P·0km/h로 두었다. 세션은 열린 채(뒷문 열기 전)
