# 뱃속 소리 음원 (후보 C118)

`app/src/main/assets/sound/womb.m4a`를 만드는 스크립트다. 내려받은 소리 없이 직접 합성한다.

## 만든 방법
- **박동:** 72회/분(60초에 정확히 72박). 박마다 '쿵(55Hz)–쿵(65Hz, 55% 크기, 0.3초 뒤)'. 8ms 어택, 약 70ms 감쇠, 기본음은 살짝 내려가고 2·3배음(약 110~195Hz)을 약하게 얹어 차 스피커에서도 들리게 했다.
- **'쉬' 소리:** 60초 흰잡음(고정 시드 118)을 FFT 영역에서 700Hz 위로 12dB/옥타브 줄이고 핑크 쪽으로 기울였다. 원형 필터라 처음과 끝이 이어진다. 박동 주기(1.2Hz)로 크기가 ±15% 오르내린다.
- **이음새:** 박은 0.25초 비껴 시작해 반복 이음새가 박 사이 빈 곳에 놓인다. 끝을 넘는 꼬리는 처음으로 이어 붙인다.
- **음량:** −30.0 LUFS(ffmpeg ebur128, loudnorm 아님)를 잰 값으로 이득을 계산해 맞춘다. AAC-LC 64kbps 모노 44.1kHz(자장가와 같은 꼴).

## 실행
```
python3 tools/sound/womb.py          # 생성 + ffprobe·ebur128 출력
python3 tools/sound/womb.py --check  # 두 번 이어 붙인 PCM의 이음새 검사
```
numpy, ffmpeg/ffprobe 필요. 같은 입력이면 m4a가 바이트까지 같게 나온다(두 번 돌려 `shasum` 확인).

## 잰 값
길이 60.000초, AAC-LC, 모노, 44.1kHz, 약 64kbps, 통합 음량 −30.0 LUFS, 정점 −13.2 dBFS, 493,175바이트(약 482KB).

## 라이선스
직접 합성했고 저장소 라이선스를 따른다. 외부 음원 없음.

## 한계
소리 설계 참고는 자궁 안 소리(심장 박동과 혈류의 낮은 '쉬' 소리)이고, 차 안에서 달래는 효과는 검증되지 않았다.
