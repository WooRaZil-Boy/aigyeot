아이곁 에뮬레이터 YAMNet + 울음 판별층 대조 (2026-11-02)

목적: 공식 Pleos 에뮬레이터(AVD PleosProbe, 운전자 user 10)의 YAMNet + 울음 판별층이 맥 파이썬(MediaPipe 0.10.14)과 같은 확률을 내는지 확인한다.
파일: 6개 시험 PCM(16kHz mono s16le, 10초, 3초 구간 9개씩), yamnet.tflite, cry_head24_rt.json
만든 방법:
  python tools/cry-retrain/mk_pcm.py <데이터 폴더>     # PCM 6개와 맥 기준값(ref.json, 소수 둘째 자리 반올림)
  # 프로브 설치·권한은 README 2장. 입력 파일을 앱 files 폴더(user 10)에 넣는다. S는 mk_pcm이 쓴 데이터 폴더(경로는 환경에 맞게)
  D=/data/user/10/dev.probe.pleos/files
  adb shell run-as dev.probe.pleos --user 10 mkdir -p $D   # 갓 설치한 앱에는 files 폴더가 아직 없다
  for f in S/assets/rt/*.pcm S/dl/yamnet.tflite S/cry/cry_head24_rt.json; do adb shell "run-as dev.probe.pleos --user 10 sh -c 'cat > $D/$(basename $f)'" < $f; done
  adb logcat -c
  adb shell am start -W --user 10 -n dev.probe.pleos/.SoundProbe --es cmd yamnet
  sleep 15
  adb logcat -d -s SOUND:I
읽는 법: 1) 아래 SOUND 로그 원문(YAMNET은 상위 클래스, HEAD가 판별층 울음 확률과 경보). 2) 비교표는 구간 9개의 울음 확률을 맥/기기로 나란히 놓고 절댓값 차이의 최댓값과 경보(맥/기기)를 적었다.
한계: 두 쪽 모두 소수 둘째 자리로 찍히므로 비교는 0.01 단위다. 그보다 작은 차이는 이 로그로 알 수 없다.
